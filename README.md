# 🌍 GeoGuardian

### AI-Powered Location Intelligence & Safety Platform

GeoGuardian is a web-based location safety platform that helps users understand the safety conditions of a city or place before travelling or moving around.

The platform provides multiple safety-related services in one place, including **crime information, live weather updates, disaster alerts, local news, emergency contacts, AI-based safety scoring, and maps**.

## 🚀 Features

- 🛡️ **Crime Report** – Provides crime-risk information and safety tips for the selected location.
- 🌦️ **Live Weather** – Displays real-time weather information such as temperature, humidity, weather condition, and wind speed.
- 🚨 **Disaster Alerts** – Shows disaster-risk information, alerts, and safety recommendations.
- 📰 **Local News** – Provides local news and location-based updates.
- 🏥 **Emergency Services** – Displays emergency contact information such as police, ambulance, and fire services.
- ⭐ **AI Safety Score** – Provides an overall safety score and recommendation for the selected location.
- 🗺️ **Maps** – Helps users find nearby police stations, hospitals, and other location services.

## 🔍 How It Works

1. User enters a **city or place name**.
2. User clicks **Analyze Location**.
3. GeoGuardian identifies the selected location.
4. The platform collects and processes the available safety information.
5. The results are displayed in separate sections for easy understanding.
6. Users can view detailed information through the individual feature buttons.

## 🌦️ Live Weather Integration

GeoGuardian uses the **Open-Meteo API** to retrieve live weather information based on the selected location.

The application first converts the entered city name into geographical coordinates and then uses the coordinates to retrieve current weather conditions.

## 📰 Live Local News

The Local News module is designed to provide location-based news updates for the selected city or place.

The system can be integrated with a news API to retrieve current news based on the user's searched location.
