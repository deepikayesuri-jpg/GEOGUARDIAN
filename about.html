🌍 About GeoGuardian

GeoGuardian is an AI-powered Location Intelligence and Safety Assessment Platform designed to help users understand the safety conditions of a place before travelling or moving.

🎯 Project Objective

The main goal of GeoGuardian is to combine crime information, weather conditions, disaster alerts, emergency services and AI-based safety analysis into one platform.

🛠 Technologies Used

💻 HTML - Website Structure

🎨 CSS - User Interface Design

⚙️ JavaScript - Logic & Data Processing

📂 JSON - Data Storage

🌐 APIs - Future Real-Time Data Integration

🚀 Project Modules

  • 🛡 Crime Analysis
  • 🌦 Weather Monitoring
  • 🚨 Disaster Alerts
  • 📰 Local News Information
  • 🏥 Emergency Services
  • ⭐ AI Safety Score
  • 🗺 Location Services
